FREDDY'S SOLUTIONS - ESTRUCTURA DEL PROYECTO

Archivos:
- index.html: estructura y contenido de la página.
- css/styles.css: todos los estilos que antes estaban dentro de <style>.
- js/main.js: toda la lógica JavaScript que antes estaba dentro de <script>.
- assets/images/trabajos/: coloca aquí las seis imágenes WebP de la galería:
  antes1.webp, despues1.webp, antes2.webp, despues2.webp, antes3.webp, despues3.webp.
- assets/icons/: iconos adicionales.
- assets/fonts/: tipografías locales.
- documents/: catálogos y documentos descargables.

IMPORTANTE ANTES DE PUBLICAR:
1. Abre js/main.js y reemplaza WHATSAPP_NUMERO = "1234567890" por tu número real,
   con código de país, sin +, espacios ni guiones.
2. En js/main.js, agrega las URL reales de Facebook, Instagram y TikTok en REDES.
3. Agrega las seis fotos WebP indicadas en assets/images/trabajos/.
4. Revisa que la dirección, horarios, servicios, garantías y afirmaciones comerciales
   de index.html sean correctos.
5. El formulario actual prepara un mensaje y abre WhatsApp; no guarda solicitudes
   en una base de datos ni envía archivos a un servidor.

Para probar:
- Abre la carpeta freddys-solutions-web en Visual Studio Code.
- Ejecuta index.html con Live Server.
